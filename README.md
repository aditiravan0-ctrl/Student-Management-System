# Student Management System

## Overview

The Student Management System is a console-based application developed in C++ that helps manage student records efficiently. The system allows users to add, search, update, delete, and display student information through a simple menu-driven interface.

## Features

* Add new student records
* Display all student records
* Search student by ID
* Update existing student details
* Delete student records
* Persistent data storage using file handling
* User-friendly menu-driven operations

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling (fstream)

## How It Works

The application stores student data in a file, ensuring that records remain available even after the program is closed. Users can perform various operations through a menu-driven interface, making record management simple and efficient.

## Expected Outcome

A functional Student Management System that enables reliable storage and management of student records with support for add, update, delete, search, and display operations.
